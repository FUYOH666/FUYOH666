Building AI-operated systems for complex, high-value workflows.

The focus is on turning fragmented documents, decisions and operational processes into structured software systems using models, retrieval, tools, verification and human oversight where it matters.

Current work spans agentic systems, document intelligence, evidence-grounded AI, private inference and workflow automation.

The underlying thesis is simple: a growing share of organizational work will move from people operating software to software operating workflows.
